# Implementation Plan: `v0.6` — Body Weight (Trend Weight), Measurements & CSV Import/Export

> **Agent Prompt**: Implement `v0.6` according to this plan. Prerequisite: `v0.5` is complete. Read `docs/04-nutrition-and-tdee-spec.md` for Trend Weight details.

## 1. Goal & Scope

Build the **Body Weight & Measurements** module featuring MacroFactor-style **Exponentially Smoothed Trend Weight** plotted against daily Scale Weight and Goal Weight, a 13-site tape measurement & Body Fat % tracker, and the **Universal CSV/JSON Importer** (Strong, Hevy, FitNotes, Apple Health) & **Full Backup Exporter**.

- **In Scope**: Time-gap-aware EWMA Trend Weight math (`packages/shared`), dual-line Scale vs. Trend Weight chart with goal line & weekly rate, Body Fat % & tape measurements CRUD + sparklines, CSV importers for Strong/Hevy/FitNotes/Apple Health with fuzzy exercise matching, full JSON/CSV/SQLite backup exporter.
- **Out of Scope**: Progress photos (`v1.5` backlog), Calorie/Protein logging (`v0.7`).

## 3. Step-by-Step Implementation Tasks

### Step 1: MacroFactor Trend Weight (EWMA) Engine (`packages/shared`) (Linear 6.1)
1. In `packages/shared/src/trend-weight.ts`, implement `computeTrendWeightSeries(entries, alpha0 = 0.15)`:
   - Sort weigh-ins chronologically by `date` (`YYYY-MM-DD`).
   - For the first entry, `trendWeightLb = scaleWeightLb`.
   - For subsequent entries $t$ separated by $\Delta d$ days from entry $t-1$:
     $$\alpha_d = 1 - (1 - \alpha_0)^{\Delta d}$$
     $$\text{Trend}_t = \alpha_d \cdot \text{Scale}_t + (1 - \alpha_d) \cdot \text{Trend}_{t-1}$$
   - Compute `weeklyRateLb` ($\text{Trend}_t - \text{Trend}_{t-7\text{d}}$), `projectedGoalDate`, and Lifts as a `% of Trend Weight`.
2. Write comprehensive unit tests in `trend-weight.test.ts` verifying daily weigh-ins, multi-day gaps, and water-weight spike dampening.

### Step 2: Weight Chart & Body Measurements UI (Linear 6.1 & 6.2)
1. Build `WeightTrendChart`:
   - Plots **Scale Weight** as subtle translucent dots/dashed line and **Trend Weight** as a bold gradient curve, overlaid against the user's **Goal Weight Line** and target weekly rate band (`Lose`, `Gain`, or `Hold`).
   - Header KPI pills: `Current Trend Weight`, `Latest Scale Weight`, `7-Day Rate (lb/wk)`, and `Distance to Goal`.
2. Build `TapeMeasurementsCard`:
   - Log Body Fat % (with optional Navy Method estimator from `neck`, `waist`, `hips`, and `height`) and 13 circumference sites (`neck`, `shoulders`, `chest`, `waist`, `hips`, `left/right bicep`, `left/right forearm`, `left/right thigh`, `left/right calf`).

### Step 3: Universal CSV Importer & Full Backup Exporter (Linear 6.3)
1. In `packages/shared/src/importers/csv-workout-importer.ts`:
   - Auto-detect CSV headers from **Strong**, **Hevy**, and **FitNotes**.
   - Map imported exercise names to the 5,632-exercise catalog (exact match $\rightarrow$ normalized token match $\rightarrow$ custom exercise creation fallback, with a review table before committing).
   - Group rows into `workouts`, `workout_exercises`, and `workout_sets`, and recalculate `personal_records`.
2. Build `ExportDataCard` in `Settings`:
   - **Export Everything (JSON)**: Single portable JSON file containing all user tables.
   - **Export Workouts (CSV)** & **Export Body/Nutrition (CSV)**: Spreadsheet-ready exports.
   - **Download Raw SQLite Database (`.sqlite3`)**: Reads the raw bytes from the OPFS SQLite file and downloads `gains-backup-YYYY-MM-DD.sqlite3`.

4. Go to **Settings $\rightarrow$ Import & Export**:
   - Export a **Full JSON Backup** and **Workouts CSV**.
