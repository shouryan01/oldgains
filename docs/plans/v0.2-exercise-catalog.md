# Implementation Plan: `v0.2` — Exercise Catalog (5,632 Exercises) & Custom Exercises

> **Agent Prompt**: Implement `v0.2` according to this plan. Prerequisite: `v0.1` is complete. Read `docs/03-gym-and-progression-spec.md` and `catalog/README.md` for reference.

---

## 1. Goal & Scope

Compile all 5,632 base exercises (and link the 922 female variants) from `catalog/exercises/*.json` into a fast-loading asset seeded into local SQLite with **FTS5 Full-Text Search**, build the interactive **17-region Front/Back SVG Anatomical Muscle Map**, implement the **Exercise Library** with multi-facet filtering and detail views, and allow users to create/edit **Custom Exercises**.

- **In Scope**: Catalog build script (`scripts/build-catalog.ts`), SQLite `exercises_fts` virtual table, 17-region SVG Muscle Map component, virtualized Exercise Library search & filters, Exercise Detail sheet/page, Custom Exercise CRUD modal.
- **Out of Scope**: Exercise video/image media from `catalog/media` (`v1.4`), active workout logging (`v0.4`).

## 3. Step-by-Step Implementation Tasks

### Step 1: Catalog Compiler Script & Muscle Map Normalization (Linear 2.1)
1. In `packages/shared/src/catalog-types.ts`, define exact union types and Zod validators for all catalog enums:
   - **11 Body Parts**: `'waist' | 'upper arms' | 'back' | 'chest' | 'upper legs' | 'shoulders' | 'lower arms' | 'lower legs' | 'neck' | 'full body' | 'cardio'`
   - **34 Equipment Types**, **12 Categories**, **19 Targets**, and **17 `MuscleMapKey`s** (`'chest' | 'upper-back' | 'lower-back' | 'trapezius' | 'deltoids' | 'biceps' | 'triceps' | 'forearm' | 'abs' | 'obliques' | 'serratus' | 'gluteal' | 'quadriceps' | 'hamstring' | 'adductors' | 'hip-flexors' | 'calves'`).
2. In `packages/shared/src/muscle-map.ts`, write `resolveExerciseMuscleMap(exercise)`:
   - If the exercise JSON already includes `muscleMap.weights`, use it directly.
   - Otherwise, deterministically compute `primaries`, `secondaries`, and `weights` (`1.0` for primary target mapped to `MuscleMapKey`, `0.4` for each `secondaryMuscles` entry) so 100% of exercises render accurately on the body map.
3. In `scripts/build-catalog.ts`:
   - Read all 6,554 JSON files in `catalog/exercises/`.
   - Filter out entries with `variantOf` (the 922 female variants, which are already linked via `femaleVariant` on the 5,632 base exercises).
   - Output `apps/web/public/catalog-exercises.json`.
4. In `packages/db/src/catalog-loader.ts` & `fts.ts`:
   - On first database initialization, check if `SELECT count(*) FROM exercises WHERE is_custom = 0` matches 5,632. If not, fetch `/catalog-exercises.json` and bulk-insert all 5,632 rows inside a single SQLite `BEGIN TRANSACTION ... COMMIT` (takes `<300ms` in `sqlite-wasm`), then populate `exercises_fts`.

### Step 2: 17-Region Interactive SVG Anatomical Body Map (Linear 2.2)
1. Build `AnatomicalBodyMap` (`apps/web/src/components/body-map/anatomical-body-map.tsx`) rendering Anterior (Front) and Posterior (Back) anatomical figures with distinct SVG `<path>` groups for all 17 `MuscleMapKey`s.
2. Support three props modes:
   - `weights: Partial<Record<MuscleMapKey, number>>` (`0.0` to `1.0` intensity mapped to a sleek iOS gradient from subtle slate to vibrant emerald/coral).
   - `size: 'mini' | 'sm' | 'md' | 'lg'` (`mini` renders a 36×36px silhouette for routine/exercise cards; `lg` renders labeled front & back figures).
   - `interactive?: boolean` with `onSelectMuscle?: (muscle: MuscleMapKey) => void` (used to filter the Exercise Library by clicking a muscle on the body, or to assign primary/secondary muscles when creating a custom exercise).

### Step 3: Exercise Library Search, Filters & Detail Sheet (Linear 2.3)
1. In `apps/web/src/routes/exercises.tsx`:
   - Connect the search input to SQLite FTS5 (`exercises_fts MATCH ?`) combined with SQL `WHERE` filters for `bodyPart`, `equipment`, `category`, `target` / `muscleMap` key, and a `"Custom Only"` toggle.
   - Add an **Interactive Body Map Filter Drawer/Toggle**: users can tap directly on the front/back body map (e.g., click `triceps` or `gluteal`) to filter exercises that train that muscle.
   - Use list virtualization (`@tanstack/react-virtual` or windowed rendering) so scrolling through all 5,632 exercises runs at 60 FPS.
2. Build `ExerciseDetailSheet`:
   - Header with capitalized exercise name, category badge, equipment badge, and `Hold` / `Unilateral` indicators.
   - Large Front/Back `AnatomicalBodyMap` showing primary (`100%`) and secondary (`40%`) muscle involvement percentages.
   - Step-by-step numbered `instructions` list and `description`.
   - **History & Records Tab**: queries `workoutSets` for this `exerciseId` to show Last Session's sets (`Weight × Reps`), Best 1RM Estimate, and historical session log.

### Step 4: Custom Exercise CRUD Modal (Linear 2.4)
1. Build `CustomExerciseModal` allowing users to create, edit, or delete custom exercises:
   - Fields: Name, Category, Equipment, Primary Body Part, Target Muscle, Secondary Muscles, Unilateral (`isPerSide`) toggle, Timed Hold (`isHold`) toggle, Description, and step-by-step Instructions.
   - Interactive `AnatomicalBodyMap` where tapping a muscle cycles it between `None (0)` $\rightarrow$ `Primary (1.0)` $\rightarrow$ `Secondary (0.4)`.
2. Saving inserts/updates both `exercises` (`is_custom = 1`) and `exercises_fts` and appends to `sync_outbox`.

## 5. Manual Verification Checklist (User Sign-Off)

1. Open the **Exercises** tab in the browser and verify all **5,632 base exercises** load into local SQLite within `<1 second` on first visit and instantaneously on subsequent reloads.
2. Type `"incline dumbbell"` or `"bench press"` in the search bar and verify FTS5 search results update as you type with zero lag.
3. Filter by:
   - **Equipment**: `barbell`, `cable`, `body weight`
   - **Category**: `strength`, `stretching`, `calisthenics`
   - **Interactive Body Map**: Click on the **Chest** or **Hamstrings** region on the SVG body diagram and verify the list filters to exercises targeting that muscle.
4. Click on **"Barbell Close-Grip Bench Press"** (`0030`) to open the Exercise Detail view:
   - Verify the SVG Muscle Map lights up **Triceps** as Primary (`100%`) and **Chest / Deltoids** as Secondary (`40%`).
   - Verify the 6 numbered instruction steps and description render cleanly.
5. Click **"New Custom Exercise"**:
   - Create a custom exercise, tap muscles on the body map to set primary/secondary weights, save it, and verify it is immediately searchable via FTS5 and can be edited or deleted.
