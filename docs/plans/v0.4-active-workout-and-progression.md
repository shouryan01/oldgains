> **Agent Prompt**: Implement `v0.4` according to this plan. Prerequisite: `v0.3` is complete. Read `docs/03-gym-and-progression-spec.md` for reference.

## 1. Goal & Scope

Build the live **Active Workout Player** (both Guided Routine sessions and Freestyle workouts), automatic **Rest Timer** (with Screen Wake Lock & loud-gym visual flash), **Plate & Machine Stack Calculator**, 1-tap **Backup Exercise Swap**, the **BuiltWithScience+ Intra-Workout "Pocket Coach"**, live PR detection, the **Multi-Mode Progression Engine**, and the **Workout Complete Summary Screen** (with muscle map, PR trophies, and next session target review).

- **In Scope**: Guided & Freestyle workout execution, pre-filled targets + "Last Time" column, rest timer + wake lock + visual flash, RPE/RIR effort picker, plate math calculator, custom machine stacks, backup/similar-muscle swap, BWS+ Pocket Coach nudge, live PR detection, Progression & Stall/Deload engine, Workout Complete summary.
- **Out of Scope**: Long-term multi-month analytics charts (`v0.5`), Apple Watch companion (`v1.2`).

## 3. Step-by-Step Implementation Tasks

### Step 1: Progression Engine, Pocket Coach, 1RM & Plate Math (`packages/shared`) (Linear 4.3 & 4.4)
1. Implement `packages/shared/src/progression-engine.ts`:
   - `calculateNextSessionTargets(progressionRule, completedWorkingSets, historyStallCount, machineStack?)`:
     - **Linear**: All working sets hit target reps $\rightarrow$ `+incrementLb`.
     - **Greyskull LP**: Last working set is AMRAP (`5+`). `<5 reps` $\rightarrow$ `-10%` deload; `5–9 reps` $\rightarrow$ `+incrementLb`; `10+ reps` $\rightarrow$ `+2 * incrementLb`.
     - **Double Progression**: Within `[repRangeMin, repRangeMax]`. Increments target reps until all sets hit `repRangeMax` (at `RIR >= 1` if logged), then adds `incrementLb` and resets target reps to `repRangeMin`.
     - **Triple Progression**: Progresses reps to `repRangeMax` $\rightarrow$ adds 1 working set up to `setRangeMax` $\rightarrow$ adds `incrementLb` and resets to base sets and `repRangeMin`.
     - **Timed Hold**: Adds `+5s` or `+10s` when all sets reach target hold duration.
     - **Stall & Deload Rule**: Missed reps never add load (`nextWeight = currentWeight`). If an exercise fails to progress for `stallSessionsThreshold` (default 2) consecutive sessions, flag `isDeloadRecommended: true` (`-10%` load) with a human-readable explanation badge.
     - If a custom `machineStack` array is configured for the exercise, snap recommended weights to the nearest valid stack pin.
2. Implement `packages/shared/src/pocket-coach.ts` (BuiltWithScience+ Intra-Workout Nudge):
   - After completing working set $k$ (where $k < \text{totalWorkingSets}$):
   - If `rir === 0` (or `rpe >= 10`) OR `reps < repRangeMin`, return a coaching recommendation for set $k+1$:
     - Option A: Add `+60s` extra rest before starting Set $k+1$
     - Option B: Drop load by `~5%` (snapped to smallest plate/stack step) so Set $k+1$ stays inside the hypertrophy target rep zone.
3. Implement `packages/shared/src/plate-calculator.ts`:
   - Given `targetWeightLb`, `barWeightLb` (Barbell 45, EZ 25, Trap 45, Smith 15), and `availablePlates` (`[45, 35, 25, 10, 5, 2.5, 1.25]`), return the exact per-side plate array and closest achievable total weight.

### Step 2: Active Workout Player & Set Logging UX (Linear 4.1)
1. Build `ActiveWorkoutPlayer`:
   - Can start from **Today's Scheduled Routine**, any routine in the library, or an empty **Freestyle Workout**.
   - Persists every single keystroke and set completion immediately to SQLite `workouts`, `workout_exercises`, and `workout_sets` (`status = 'in_progress'`). If a workout is in progress when on another tab, show a persistent mini-player bar at the bottom of the screen.
   - Top progress bar showing completed sets and **live running session volume (`totalVolumeLb`)**.
   - Supports **Quiet View** (set number acts as the set's menu; one clean menu per exercise; card vs. list view switch in Settings).
2. Build `WorkoutSetRow`:
   - Shows **"Last Time"** column (`185 × 8 @ RIR 1`) queried from the most recent completed workout containing that `exerciseId`.
   - Pre-fills today's target Weight and Reps (or Duration for timed holds / L+R reps for `isPerSide` exercises).
   - Weight `0` automatically badges the set as `Bodyweight` (with optional `+ Belt Weight` input).
   - Quick actions to **Copy Set**, **Delete Set (with Undo toast)**, or change set type (`W`, `1`, `D`, `RP`, `+`).
   - Colour-coded `RpeRirPicker` popover (`RIR 0 / RPE 10: Max Effort — 0 reps left` through `RIR 4+ / RPE 6: Warmup / Speed`).
   - When a set is marked complete inside a **Superset / Circuit**, automatically scroll/focus the paired exercise's next set!

### Step 3: Rest Timer, Wake Lock, Swap & Workout Complete Screen (Linear 4.2 & 4.5)
1. Build `RestTimerBar`:
   - Automatically starts when a set is ticked off (using `warmupRestSeconds` for warmup sets and `restSeconds` for working sets, or per-set overrides).
   - Requests `navigator.wakeLock.request('screen')` while a workout is active so the phone/laptop screen stays awake.
   - Includes `-15s`, `+15s`, custom scroll-wheel/picker up to 15 minutes, and `Skip`.
   - When the timer reaches `0:00`, plays an audio chime and (if enabled in Settings) triggers a **full-screen high-contrast visual flash** for loud gyms.
2. Build `ExerciseSwapModal`:
   - **1-Tap Backup Swap**: If the routine slot has a `backupExerciseId`, swap in 1 tap while keeping the slot's set count.
   - **Smart Muscle-Matched Alternatives**: Ranks catalog exercises by cosine similarity of `muscleMap.weights` + equipment availability (including a "Joint-Friendly / Non-Barbell" filter).
3. Build `WorkoutCompleteView`:
   - Triggered when clicking **"Finish Workout"**.
   - Displays total duration, total volume lifted, total sets, **PR Trophies** hit during the session, and the session's **Anatomical Muscle Map** summary.
   - Displays **Next Session Progression Targets** for every exercise (e.g., *"Barbell Bench Press: 185 lb × 8 → Next: 190 lb × 5 (+5 lb Linear Progression)"* or *"Deload Recommended: 165 lb (-10%)"*) with a 1-tap toggle to accept or hold the current weight.
   - If the workout was a **Freestyle Workout**, includes a **"Save as New Routine"** button.

## 5. Manual Verification Checklist (User Sign-Off)

1. From the **Home** or **Routines** screen, start a **Guided Workout** and verify target weights/reps are pre-filled and the **"Last Time"** column shows previous performance.
2. Tap a barbell weight input to open the **Plate Calculator** and verify it displays the per-side plates (e.g., `225 lb` = two `45 lb` plates per side).
3. Complete Set 1 of an exercise with `RIR 0` (all-out failure) and verify:
   - The **Rest Timer** starts automatically.
   - The **BWS+ Pocket Coach** badge appears above Set 2 suggesting `+60s rest` or a `-5% weight drop` (with 1-tap apply buttons).
4. Test **1-Tap Backup Exercise Swap** on an exercise slot and verify the replacement swaps in cleanly.
5. Log a heavier weight/rep combination than ever before and verify the live **PR Trophy Badge** lights up on that set row.
6. Refresh the page mid-workout and verify the active session and running timer state resume without losing a single set.
7. Click **"Finish Workout"** and verify the **Workout Complete Screen** shows the session Muscle Map, PRs, total tonnage, and the auto-calculated **Next Session Progression Targets** (and verify you can toggle any target between Progress and Hold).
