# Implementation Plan: `v1.2` — Apple Watch Companion App (`ios/GainsWatch`)

> **Agent Prompt**: Implement `v1.2` according to this plan. Prerequisite: `v1.1` is complete. Read `docs/06-ios-watch-and-wrapped-spec.md` for reference.

---

## 1. Goal & Scope

Build the native **Apple Watch Companion App (`ios/GainsWatch`)** supporting both **standalone wrist execution** (when the iPhone is in a gym locker) and **real-time two-way mirroring** with the iPhone app, featuring **Digital Crown** weight/rep dialing with haptic detents, **Multi-Stage Haptic Rest Timer**, RPE/RIR picker, **Crown/Sweat Lock**, 1-tap Backup Exercise Swap, per-set **Live Heart Rate (`HKLiveWorkoutBuilder`)**, and **Watch Face Complications**.

- **In Scope**: `GainsWatch` watchOS app target + `GainsWatchWidgets` complication target, `WatchConnectivity` (`WCSession`) + watchOS 10+ `HKWorkoutSession` mirroring, Digital Crown set logger, multi-stage haptic rest timer (`WKHapticType`), RPE/RIR wrist picker, Crown Lock mode, backup exercise swap, live HR capture per set, Watch Face Complications.
- **Out of Scope**: Full routine creation on the watch screen (routines are synced from iPhone/Cloud).

## 3. Step-by-Step Implementation Tasks

### Step 1: WatchConnectivity & `HKWorkoutSession` Live Mirroring (Linear 13.1)
1. Implement `WatchSyncManager.swift` on both iOS and watchOS using `WCSession`:
   - Syncs the user's routines, schedule, and recent exercise history to the Watch's local `GRDB` SQLite database so the Watch can start and log a full workout **completely offline / standalone** even when out of Bluetooth range of the iPhone.
   - When in range, uses `sendMessage` (interactive real-time) + `transferUserInfo` (guaranteed delivery queue) so ticking off a set on the Watch immediately ticks it off on the iPhone screen and iPhone Lock Screen Live Activity (and vice versa).
2. Implement `WatchWorkoutSessionManager.swift` using `HKWorkoutSession` and `HKLiveWorkoutBuilder`:
   - Starts a `.traditionalStrengthTraining` session on the Watch so watchOS keeps the app pinned as the active frontmost session whenever you raise your wrist.
   - Records live heart rate samples during each working set and writes `heart_rate_avg` onto the completed `workout_sets` row.

### Step 2: Digital Crown Set Logger, Crown Lock & Multi-Stage Haptic Rest Timer (Linear 13.2)
1. Build `DigitalCrownSetLoggerView.swift`:
   - Tap the **Weight** pill or **Reps** pill to bind `.digitalCrownRotation(...)` with `.sensoryFeedback(.selection, trigger:)`.
   - Displays compact `"Last: 185×8"` and `"Target: 185×9"` labels at the top of the screen.
   - Primary green **"Complete Set"** button triggers optional 1-tap `WatchRpePickerSheet` (if enabled) and starts the rest timer.
   - **Crown / Sweat Lock**: Toggle button in the top-left corner that disables Digital Crown and accidental taps during pushups/straps until long-pressed for 1.5 seconds.
   - **PR Celebration**: If a completed set breaks a 1RM or weight PR, play `WKInterfaceDevice.current().play(.success)` and flash a full-screen gold PR trophy banner for 2 seconds.
2. Build `WatchRestTimerView.swift`:
   - Full-screen circular countdown ring with `-15s`, `+15s`, and `Skip` buttons.
   - Schedules a `WKExtendedRuntimeSession` / background timer that plays:
     - **15 Seconds Remaining**: `WKInterfaceDevice.current().play(.directionUp)` ("get back to the bar" gentle nudge).
     - **0:00 Rest Complete**: `WKInterfaceDevice.current().play(.notification)` (strong double-buzz).

### Step 3: Watch Face Complications (`WidgetKit`) (Linear 13.3)
1. Build `WatchComplications.swift` supporting `.accessoryCircular`, `.accessoryCorner`, and `.accessoryRectangular`:
   - **Today's Routine Complication**: Shows next scheduled routine (e.g., `"Push A"`) and taps straight into starting that workout.
   - **Weekly Gym Streak Complication**: Shows workouts completed this week (`3/4`).
   - **Daily Protein / Calories Complication**: Dual gauge for remaining daily protein and calories.

## 5. Manual Verification Checklist (User Sign-Off)

1. Run the `Gains` iOS + `GainsWatch` paired schemes in Xcode (or on your iPhone + Apple Watch).
2. Start today's scheduled routine from the **Apple Watch**:
   - Verify the workout automatically mirrors onto your iPhone and Lock Screen Live Activity.
3. Rotate the **Digital Crown** to adjust weight and reps, tap **Complete Set**, and verify:
   - Set completion syncs immediately to the iPhone.
   - The **Watch Rest Timer** starts and triggers the 15-second warning haptic and 0:00 completion haptic.
4. Test **Crown Lock** mode and **1-Tap Backup Exercise Swap** from the Watch exercise menu.
5. Finish the workout on the Watch and verify `heart_rate_avg` is saved on your logged sets and your Apple Watch Exercise/Move rings advance.
