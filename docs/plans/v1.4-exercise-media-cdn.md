# Implementation Plan: `v1.4` — Exercise Media CDN (Cloudflare R2)

> **Agent Prompt**: Implement `v1.4` according to this plan. Prerequisite: `v0.10` is complete. Inspect `catalog/media/` and `docs/01-architecture-and-tech-stack.md`.

---

## 1. Goal & Scope

Serve the **216 MB of exercise visual demonstrations** (`catalog/media/still/*.webp` — 46 MB, and `catalog/media/clip/*.mp4` — 170 MB) lazily from **Cloudflare R2** (10 GB/mo free tier, zero egress fees) so the Exercise Library, Routine Builder, and Active Workout screens display crisp thumbnails and looping animated form demos without bloating the initial app bundle.

- **In Scope**: R2 bucket binding in `apps/api/wrangler.toml`, bulk upload script (`scripts/upload-catalog-media-r2.ts`), cached `/api/media/still/:id.webp` and `/api/media/clip/:id.mp4` Worker delivery route (or custom R2 public domain), lazy-loaded `<ExerciseMediaPreview />` component on Web and iOS, and Settings toggle for Male vs. Female (`femaleVariant`) demonstration figures and Offline Media Prefetch.
- **Out of Scope**: User progress photos (`v1.5`).

## 3. Step-by-Step Implementation Tasks

### Step 1: Cloudflare R2 Bucket & Upload Script (Linear 15.1)
1. Add the R2 bucket binding (`MEDIA_BUCKET`) to `apps/api/wrangler.toml`.
2. Create `scripts/upload-catalog-media-r2.ts` to upload `catalog/media/still/*.webp` and `catalog/media/clip/*.mp4` (in local dev, `apps/api/src/routes/media.ts` can also serve directly from `/catalog/media/` on disk when running on localhost!).
3. In `apps/api/src/routes/media.ts`, serve `/api/media/still/:id` and `/api/media/clip/:id` with Cloudflare Edge Cache + `Cache-Control: public, max-age=31536000, immutable` so each file is read from R2 at most once per edge location.

### Step 2: Lazy-Loaded Exercise Thumbnails & Animated Clips (Linear 15.1)
1. Build `ExerciseMediaPreview`:
   - Uses `loading="lazy"` for `still/<id>.webp` thumbnails in the virtualized Exercise Library list.
   - Plays `clip/<id>.mp4` (`<video autoPlay loop muted playsInline>`) only when the Exercise Detail sheet or Active Workout help popover is open.
   - Respects the user's preferred demonstration figure in Settings: if set to `Female` and the exercise has a `femaleVariantId` (e.g., `0030` $\rightarrow$ `2391`), automatically loads `still/2391.webp` and `clip/2391.mp4`!
   - Gracefully falls back to the mini `AnatomicalBodyMap` SVG icon if offline and the image hasn't been cached yet.
