# Implementation Plan: `v1.0` — Native iOS App Core (SwiftUI + `SQLiteData` / `GRDB.swift`)

> **Agent Prompt**: Implement `v1.0` according to this plan. Prerequisite: `v0.10` is complete. Read `docs/06-ios-watch-and-wrapped-spec.md` and `docs/02-database-and-sync-spec.md` for reference.

---

## 1. Goal & Scope

Build the native **Swift 6 + SwiftUI iOS Application (`ios/Gains`)** powered by **`SQLiteData` (`GRDB.swift`)**, running the exact same SQLite schema, bundled 5,632-exercise FTS5 catalog, and HLC Delta Sync engine as the Web app.

- **In Scope**: Xcode project (`ios/Gains`), Swift Package Manager dependencies (`SQLiteData` / `GRDB.swift`), SQLite migration runner & FTS5 search, HLC Delta Sync client + Passkey/Token sign-in, native SwiftUI Exercise Library & 17-region Muscle Map view, Routine Builder, and Active Workout Player on iPhone.
- **Out of Scope**: Apple HealthKit, Lock Screen Live Activities & Widgets (`v1.1`), Apple Watch companion (`v1.2`).

## 3. Step-by-Step Implementation Tasks

### Step 1: SQLite Database (`SQLiteData` / `GRDB.swift`) & HLC Sync (Linear 11.1)
1. Configure `AppDatabase.swift` using `GRDB` `DatabasePool` (WAL mode enabled) in the App Group shared container (`group.com.gains.app`, so iPhone, Widgets, Live Activities, and Apple Watch can share access).
2. Define `@Table` Swift structs matching every column in `packages/db/src/schema.ts`.
3. Implement `CatalogSeeder.swift` to bulk-insert the 5,632 base exercises into SQLite and `exercises_fts` on first launch in `<200ms`.
4. Implement `HLCSyncService.swift` to push `sync_outbox` mutations to `POST /api/sync/push` and pull deltas from `GET /api/sync/pull`.

### Step 2: SwiftUI Exercise Library, SVG Muscle Map & Routine Builder (Linear 11.2)
1. Build `AnatomicalBodyMapView.swift` using SwiftUI `Canvas` / `Path` with the exact same 17 anatomical muscle vector paths as `apps/web`.
2. Build `ExerciseLibraryView` & `ExerciseDetailView` using `@FetchAll` and Swift Charts (`SectorMark` / `AreaMark` with linear gradients) for 1RM progression curves.
3. Build `RoutineListView` and `RoutineEditorView` supporting starter plans, supersets, backup exercises, and Fixed Weekday / Rolling Rotation scheduling.

### Step 3: Native Active Workout Player & Progression Engine (Linear 11.3)
1. Build `ActiveWorkoutView` with native iOS keyboard toolbar (`+2.5`, `-2.5`, `Plate Calc`, `RPE/RIR`, `Next Set`), haptic feedback on set completion (`UIImpactFeedbackGenerator`), `UIApplication.shared.isIdleTimerDisabled = true` while training, and background local notifications when the rest timer finishes.
2. Implement `ProgressionEngine.swift` and `WorkoutCompleteView.swift` matching the Web app's progression and Pocket Coach behavior 1:1.
