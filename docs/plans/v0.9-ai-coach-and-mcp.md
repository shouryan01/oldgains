# Implementation Plan: `v0.9` — AI Coach, MCP Server & External Assistant Plugins

> **Agent Prompt**: Implement `v0.9` according to this plan. Prerequisite: `v0.8` is complete. Read `docs/05-ai-coach-and-mcp-spec.md` for reference.

---

## 1. Goal & Scope

Build the consent-first **In-App AI Coach** (Plan Architect + Weekly Training & Nutrition Review) backed by **Proposal Diff Cards (`Approve` / `Reject` / 1-Click `Undo`)**, create the **Local STDIO MCP Server (`packages/mcp`)**, add the **Remote Worker MCP Endpoint (`/api/mcp`)**, and expose the **OpenAPI 3.1 Action Schema (`/api/openapi.json`)** for ChatGPT, Claude, and Gemini plugins.

- **In Scope**: AI Coach context assembler (`packages/shared`), `ai_proposals` snapshot & 1-click Undo state machine, 5-question AI Plan Architect, Weekly Training & Nutrition Review, `packages/mcp` STDIO server, `/api/mcp` HTTP/SSE MCP handler, `/api/openapi.json` plugin schema.
- **Out of Scope**: Passkey cloud auth & multi-device D1 sync (`v0.10`).

## 3. Step-by-Step Implementation Tasks

### Step 1: AI Context Assembler & Proposal Diff / Undo Engine (`packages/shared`) (Linear 9.1)
1. In `packages/shared/src/ai-context.ts`, build `assembleCoachContext(db, reviewDays = 14)` returning what the AI Coach reads:
   - **Your Plan**: Active routines, exercises, target sets/reps, weekly schedule/rotation, and progression rules.
   - **Your Logged Training**: Completed sets in the review window (weights, reps, times, RPE/RIR ratings, session duration, session notes, stalled exercises, and fractional sets per muscle group vs. MEV/MAV/MRV).
   - **Body Weight & Composition**: Scale weigh-ins, **Trend Weight** change, Body Fat %, and Goal Weight.
   - **Nutrition & Expenditure**: Average daily calories/protein, Dynamic TDEE estimate, and weekly check-in status.
2. In `packages/shared/src/ai-proposal-engine.ts`:
   - `createProposal(type, beforeSnapshot, afterSnapshot, rationaleMarkdown)` inserts a `pending` row into `ai_proposals`.
   - `approveProposal(db, proposalId)` applies `afterSnapshot` inside a SQLite transaction and marks `status = 'approved'`.
   - `undoProposal(db, proposalId)` restores `beforeSnapshot` inside a SQLite transaction and marks `status = 'undone'`.

### Step 2: In-App AI Plan Architect & Weekly Review UI (`apps/web`) (Linear 9.2)
1. Build `PlanArchitectWizard`:
   - 5 quick steps: (1) Days/week & schedule mode (`Weekday` vs `Rotation`), (2) Session duration cap (`30m`, `45m`, `60m`, `75m+`), (3) Equipment profile, (4) Goal (`Hypertrophy`, `Strength`, `Recomp`) & priority muscles (selectable on the SVG Body Map!), (5) Joint discomfort exclusions.
   - Calls the user's configured AI provider using a tool/schema constrained to valid exercise IDs from the 5,632-exercise catalog, renders the proposed split with a combined weekly `AnatomicalBodyMap`, and saves it via a `ProposalDiffCard`.
2. Build `ProposalDiffCard` & `ProposalHistoryList`:
   - Shows side-by-side red/green diffs for added/swapped exercises, set/rep adjustments, progression tweaks, or calorie/protein updates.
   - Every approved proposal in `ProposalHistoryList` has a permanent **"Undo Change"** button.

### Step 3: Local STDIO MCP Server (`packages/mcp`) & OpenAPI Plugin Spec (Linear 9.3)
1. Implement `packages/mcp/src/tools.ts` using `@modelcontextprotocol/sdk`:
   - `search_exercises`: FTS5 search across the 5,632-exercise catalog.
   - `get_training_summary`: Returns routines, logged workouts, 1RM records, and muscle volume for a date window.
   - `get_nutrition_and_tdee`: Returns nutrition logs, Trend Weight, and Dynamic TDEE.
   - `log_workout_session`: Logs a completed workout from natural language sets/reps.
   - `log_nutrition_items`: Logs food items (grams, calories, protein) to a date/meal slot.
   - `log_body_weight`: Logs scale weight and body fat %.
   - `propose_routine_change`: Creates a pending `ai_proposals` record for user review.
2. Expose the same tools via `/api/mcp` and generate `/api/openapi.json` on the Hono API server so users can connect Claude Desktop, Cursor, Gemini CLI, or a Custom GPT in ChatGPT.

## 5. Manual Verification Checklist (User Sign-Off)

1. Open **Routines $\rightarrow$ AI Coach** and run the **5-Question Plan Architect**:
   - Select `4 days/week`, `60 min`, prioritize `Chest & Side Delts`, and generate a plan.
   - Verify the **Proposal Diff Card** shows all routines, exercises, sets/reps, and the combined weekly Muscle Map.
   - Click **"Approve Plan"** to import the routines, then click **"Undo"** in the Proposal History list and verify the routines revert to their exact prior state.
2. Run **"Weekly Training & Nutrition Review"**:
   - Verify the AI Coach reads your logged sets, RPE, stalled lifts, Trend Weight, and TDEE, and presents a structured Proposal Diff Card.
3. Run the local MCP server test (`node packages/mcp/dist/index.js` or via MCP Inspector) and verify `search_exercises` and `get_training_summary` return structured JSON.
