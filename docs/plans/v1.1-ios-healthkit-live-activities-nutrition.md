# Implementation Plan: `v1.1` — iOS HealthKit, Lock Screen Live Activities, Widgets & Nutrition

> **Agent Prompt**: Implement `v1.1` according to this plan. Prerequisite: `v1.0` is complete. Read `docs/06-ios-watch-and-wrapped-spec.md` for reference.

---

## 1. Goal & Scope

Extend the native iOS app with **Lock Screen Live Activities & Dynamic Island (`ActivityKit`)**, bi-directional **Apple Health (`HealthKit`)** sync, **Home Screen & Lock Screen Widgets (`WidgetKit`)**, native iOS **Nutrition & Adaptive TDEE** views with hardware camera Barcode & Label OCR scanning, and an optional on-device **Gym Arrival Geofence Reminder**.

- **In Scope**: `ActivityKit` Live Activity & Dynamic Island with interactive `AppIntent` buttons (`Complete Set`, `+15s`, `Skip`), bi-directional `HealthKit` manager, `WidgetKit` extension (3 widget families), native SwiftUI Nutrition & TDEE views + `DataScannerViewController` barcode/OCR scanner, optional `CoreLocation` gym geofence reminder.
- **Out of Scope**: watchOS companion app (`v1.2`).

## 3. Step-by-Step Implementation Tasks

### Step 1: Lock Screen Live Activity & Dynamic Island (`ActivityKit`) (Linear 12.1)
1. Define `WorkoutActivityAttributes` in the shared target containing static workout metadata and `ContentState` (`currentExerciseName`, `setNumber`, `totalSets`, `targetWeightLb`, `targetReps`, `restEndTime: Date?`, `totalVolumeLb`).
2. Build `WorkoutLiveActivityWidget` rendering:
   - **Lock Screen View**: Exercise title, Set `2 of 4` (`185 lb × 8`), live `Text(timerInterval:)` rest countdown bar, and interactive `Button(intent: CompleteSetIntent())` + `Button(intent: SkipRestIntent())`.
   - **Dynamic Island**: Compact leading exercise icon + trailing countdown timer; Expanded view with full set controls.
3. Because the app and widget extension share the App Group SQLite database (`group.com.gains.app`), tapping **"Complete Set"** on the Lock Screen writes the completed set directly to SQLite and advances the Live Activity to the next set or rest timer without opening the app!

### Step 2: Bi-Directional Apple Health (`HealthKit`) Integration (Linear 12.2)
1. Implement `HealthKitManager.swift`:
   - Request read/write authorization for `HKObjectType.workoutType()`, `bodyMass`, `bodyFatPercentage`, `heartRate`, `activeEnergyBurned`, `dietaryEnergyConsumed`, and `dietaryProtein`.
   - Set up `HKObserverQuery` on `bodyMass` and `bodyFatPercentage` so whenever a smart scale logs a morning weigh-in to Apple Health, Gains automatically imports it, recomputes **Trend Weight** & **Dynamic TDEE**, and queues it for D1 sync.
   - When a workout or meal is logged in Gains, write the `HKWorkout` and dietary samples to Apple Health (deduplicated via `HKMetadataKeyExternalUUID`).

### Step 3: Native iOS Nutrition, VisionKit Scanner & Home Screen Widgets (Linear 12.3)
1. Build `NutritionDashboardView.swift`, `CameraBarcodeScannerView.swift` (using Apple's hardware-accelerated `DataScannerViewController` for `<0.3s` barcode & Nutrition Facts text recognition), and `AiMealCaptureView.swift`.
2. Build `TodayRoutineWidget` and `NutritionRingsWidget` in `GainsWidgets` reading from the shared App Group SQLite database.
3. Implement `GymGeofenceManager.swift` (strictly opt-in, off by default in Settings): allows saving a gym location on-device and sends at most 1 local notification per day on arrival if today's workout hasn't been logged yet.

## 5. Manual Verification Checklist (User Sign-Off)

1. Start a workout on iPhone and lock the screen (or swipe home to view the **Dynamic Island**):
   - Verify the **Lock Screen Live Activity** shows the current exercise, weight/reps, and live rest countdown.
   - Tap **"Complete Set"** directly on the Lock Screen and verify the set logs and the rest timer starts without unlocking/opening the app.
2. Log a weigh-in in Apple Health (`Health` app $\rightarrow$ Body Measurements $\rightarrow$ Weight) and verify Gains automatically imports it and updates your **Trend Weight** chart.
3. Complete a workout and meal in Gains and verify they appear inside Apple's **Health** app.
4. Add the **Today's Routine** and **Calories & Protein** widgets to your iPhone Home Screen and verify they stay in sync.
