## 1. Goal & Scope

Build the complete Routine Builder, bundle 5 science-based Starter Plans (Push/Pull/Legs, Upper/Lower, Full Body, 5×5, Greyskull LP), configure exercise slots (supersets/circuits, warmup/working/drop/rest-pause/AMRAP/timed/per-side sets, rest timers, backup exercises, progression rules), implement the **Schedule Planner** (Fixed Weekday Schedule vs. Rolling Rotation `A → B → C`), and support Routine JSON & Printable PDF export.

- **In Scope**: Routine CRUD, drag-and-drop reordering, superset grouping, set templates, progression rule picker, backup exercise assignment, live Routine Muscle Map preview, 5 Starter Plans, Weekday & Rotation scheduler, Home screen "Today's Workout" card, JSON import/export & printable PDF view.
- **Out of Scope**: Live workout execution & rest timer countdown (`v0.4`).

## 3. Step-by-Step Implementation Tasks

### Step 1: Starter Plans & Schedule Engine (`packages/shared`) (Linear 3.2 & 3.3)
1. In `packages/shared/src/starter-plans.ts`, define 5 starter plan templates mapped to real catalog exercise IDs (`0025` Barbell Bench Press, `0043` Barbell Full Squat, `0032` Barbell Deadlift, etc.):
   - **Push / Pull / Legs (PPL)**: Push A, Pull A, Legs A, Push B, Pull B, Legs B
   - **Upper / Lower (4-Day)**: Upper A, Lower A, Upper B, Lower B
   - **Full Body Hypertrophy (3-Day)**: Full Body A, Full Body B, Full Body C
   - **5×5 Linear Strength**: Workout A, Workout B
   - **Greyskull LP**: Day 1, Day 2, Day 3 (with `amrap` final working sets)
2. In `packages/shared/src/schedule-engine.ts`, implement and unit-test `resolveScheduledSessions(scheduleConfig, routines, completedWorkouts, targetDate)`:
   - **Fixed Weekday Mode**: Supports week starting on Monday (`1`) or Sunday (`0`). Each weekday (`0..6`) can hold `[]` (Rest Day), `[routineId]` (fixed routine), or `[routineA, routineB, ...]` (cycles through `Upper A → Upper B` on Upper days based on which was completed last!). Also respects `dateOverrides` so a user can move today's workout to tomorrow without touching their recurring template.
   - **Rolling Rotation Mode (`A, B, C, A...`)**: Ignores weekdays; always surfaces `rotationQueue[currentRotationIndex]` as the next session.

### Step 2: Routine Builder with Supersets, Set Types, Backup Exercises & Muscle Map (Linear 3.1)
1. Build `RoutineEditor` (`apps/web/src/components/routines/routine-editor.tsx`):
   - Live header & sticky side panel showing:
     - **Live Routine Muscle Map (`AnatomicalBodyMap`)**: Aggregates `muscleMap.weights * workingSetsCount` across all exercises in the routine so you immediately see which muscles the session targets.
     - **Estimated Workout Duration**: Calculated from working sets + warmup sets + configured rest times.
   - **Exercise Slot (`RoutineExerciseSlot`)**:
     - Up/Down & drag-and-drop reordering.
     - **Link as Superset / Circuit**: Group consecutive exercises into a color-coded circuit bracket (`Superset A`, `Superset B`).
     - **Backup Exercise Picker**: Select a secondary catalog exercise for 1-tap mid-workout swapping if the machine is taken.
     - **Rest Timers**: Separate inputs for **Warmup Rest** (default `60s`) and **Working Rest** (default `120s`, scrollable/adjustable up to `15m` or `0s`).
     - **Set Rows**: Add/remove/copy sets; choose Set Type (`Warmup [W]`, `Working [1..N]`, `Drop Set [D]`, `Rest-Pause [RP]`, `AMRAP [+]`); configure target Weight (`0` = Bodyweight), Reps (or `Min–Max` range), Duration (`mm:ss` for `hold` / stretches / cardio), Per-Side toggle (`L/R`), and optional target `RIR`.
     - **Progression Rule Popover**: Select `Linear`, `Greyskull LP`, `Double Progression` (rep range `8–12` $\rightarrow$ load), `Triple Progression` (reps $\rightarrow$ sets $\rightarrow$ load), `Timed Hold`, or `None`, with configurable weight increment (`2.5 lb`, `5 lb`, `10 lb`) and deload percentage (`10%`).

### Step 3: Schedule Planner, Home Screen Integration & PDF/JSON Export (Linear 3.3 & 3.4)
1. Build `SchedulePlanner` on the `Routines` route:
   - Toggle between **Weekday Schedule** and **Rolling Rotation Queue**.
   - In Weekday mode, allow dragging/moving a session to another day for the current week and setting Monday vs. Sunday start.
   - Every day card displays a mini `AnatomicalBodyMap` icon of the muscles trained that day.
2. Update `apps/web/src/routes/index.tsx` (`Home`):
   - Show **"Today's Workout"** (or **"Rest Day — Next up: Pull A on Thursday"**) with its mini Muscle Map, exercise list preview, and a primary **"Start Workout"** CTA.
3. Implement Routine **Duplicate**, **Export/Import JSON**, and **Print / Save as PDF** (`RoutinePdfPrint` using clean `@media print` styling so `window.print()` produces a crisp 1-page gym log sheet).

## 5. Manual Verification Checklist (User Sign-Off)

1. Go to **Routines** $\rightarrow$ click **"Browse Starter Plans"** and import **Upper / Lower (4-Day)** or **Greyskull LP**.
2. Open a routine in the **Routine Editor**:
   - Add an exercise from the 5,632-exercise picker and watch the **Routine Muscle Map** and **Estimated Duration** update live.
   - Link two exercises together as a **Superset / Circuit** and verify the color-coded circuit badge appears.
   - Assign a **Backup Exercise** to one of the slots.
   - Configure a **Double Progression** rule (`8–12 reps`, `+5 lb`) on one exercise and a **Warmup + 3 Working + 1 Drop Set** template on another.
3. Open the **Schedule Planner**:
   - Test **Weekday Mode**: assign routines to days, configure Monday vs. Sunday start, and move today's session to another day for this week only.
   - Test **Rotation Mode (`A, B, C`)**: reorder the rotation queue and verify the **Home** tab updates to show the next routine with its mini Muscle Map.
4. Click **"Export JSON"** and **"Print / Save PDF"** on a routine and verify the printable layout and JSON re-import.
